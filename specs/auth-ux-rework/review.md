- Submit-time validation only — Supabase server-side validates email format and password length; client-side validation is UX layer. No security gap if JS is bypassed (Supabase returns 422).
- `friendlyAuthError` — falls through unmapped messages verbatim. Verified the fallback path is intentional and pinned by a unit test (test name: "falls through unmapped messages verbatim").
