## Decisions

_Captured during implementation when not pre-resolved by D1–D5._

- **Sentinel value**: `'__add_new__'` (double-underscored to make it visually distinct from any UUID server-issued option id). Documented inline as `ADD_NEW_SENTINEL` constant with a NEVER-send-to-server warning.
- **Divider placement in JSX**: divider lives ON the add-new button itself as a `border-t border-t-border` plus `mt-sm pt-md` for breathing room — not as a separate `<hr>` sibling. Keeps the radiogroup DOM contiguous (one button per radio, no intervening non-radio nodes), which keeps future ARIA arrow-key wiring trivial.
- **`was_force_created` event-spread shape**: in `DisambiguationSheet.handleConfirm`, the property is conditionally spread (`...(next.added_new === true ? { was_force_created: true } : {})`) instead of always passing `false`. Matches the spec's "default-omit" requirement and keeps PostHog payloads minimal for the common path.
- **Edge function `added_new` on `already_on_list` race**: per spec § API contracts step 7, set `added_new: true` whenever the request hit the force-create branch — even when the dedup `already_on_list` branch fires. Implemented as `added_new: force_create_with_label ? true : undefined` on every downstream response after the branch.
- **Defensive `chosenItem` null check after the resolution block**: TypeScript needed a type narrow because `chosenItem` is now declared above the `if (!force_create_with_label)` guard. Added an explicit "should be set by here" 500-error guard that's effectively unreachable but keeps the type system happy without overusing `!`.
- **Build verification deferred**: `pnpm turbo run build` fails locally with "Failed to fetch Plus Jakarta Sans from Google Fonts" — environment firewall, unrelated to this PR (no font-related changes in the diff). CI builds in an environment with reachable fonts; verified unaffected by checking the diff scope.
